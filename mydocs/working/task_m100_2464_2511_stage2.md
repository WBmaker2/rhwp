# 작업 2464-2511 단계 2 - 최종 통합 PR 준비

## 범위

- 최신 `upstream/devel`을 기준으로 누적 통합 브랜치의 base 관계를 확인한다.
- PR review archive 39건의 필수 항목과 통합/중복 흡수 관계를 확인한다.
- 최종 원격 push 직전에만 최신 오늘할일을 생성·갱신해 첫 PR diff에 포함한다.

## 사전 검증 결과

- `CARGO_INCREMENTAL=0 cargo test --profile release-test --tests` 통과.
- `CARGO_INCREMENTAL=0 cargo clippy --all-targets -- -D warnings` 통과.
- `cargo fmt --all -- --check` 통과.
- `wasm-pack build --target web --out-dir pkg` 통과.

## 경계

- 이 스테이지에서는 원격 push, PR 생성, 원 PR close/코멘트, merge를 수행하지 않는다.
- 오늘할일은 PR 생성 승인과 최초 push가 임박한 시점에만 작성하며, PR 번호가 필요한 문서 때문에 사후 재작성하지 않는다.
