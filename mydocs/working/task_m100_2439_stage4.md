# Task M100-2439 Stage 4 — 정상 한컴 PDF 정답지 비교

- 작성일: 2026-07-19

## 1. 기준 파일

사용자가 한컴 2024에서 가로 방향으로 인쇄한 Microsoft Print to PDF 결과를 기준으로
사용했다.

- Producer: `Microsoft: Print To PDF`
- 페이지: 10쪽
- 크기: A4 landscape 841.92×595.32pt
- 오른쪽 `31`·`비고` 열까지 잘림 없이 출력됨

rhwp 결과는 A4 landscape 841.88×595.28pt, 9쪽이다.

## 2. 내용 페이지 대응

정답지와 rhwp는 1~9쪽에 같은 양식이 같은 순서로 배치된다.

1. `02-0147`
2. `02-0202`
3. `02-0183(2)`
4. `18-0042`
5. `07-0270`
6. `18-0902`
7. `03-0279`
8. `24-0004`
9. `07-0264`

정답지 10쪽은 그려진 내용이 없는 완전한 빈 페이지다. 따라서 10쪽 대 9쪽 차이는
양식 누락이 아니라 trailing blank-page 처리 차이다.

## 3. #2439 문제 페이지 비교

정답지 6쪽과 rhwp 수정본 6쪽에서 1~16일 표와 17~31일 표가 모두 전체 높이로 순차
배치된다. 행 라벨, 셀 경계, 서명란이 한 번씩 나타나고 서로 겹치지 않는다. 수정 전의
하단 37.3px 조각과 3.8px `LAYOUT_OVERFLOW`는 재현되지 않는다.

## 4. 남은 차이

정답지는 4쪽 이후 앞 양식 안내문의 마지막 1~2줄을 다음 쪽 상단에 두고, 다음 양식의
제목·메타데이터 표를 같은 쪽에 둔다. rhwp는 안내문 전체를 앞쪽에 유지하고 다음 양식
제목이 앞쪽 하단에 놓일 수 있다. 이는 반복 표의 높이·겹침 문제가 아니라 제목/표 그룹의
orphan 및 저장 vertical-position pagination 호환성이다.

빈 10쪽 생성이나 제목 그룹 pagination을 #2439에 맞춰 휴리스틱으로 강제하지 않는다.
필요하면 별도 이슈에서 최소 fixture와 명시적 pagination 계약으로 다룬다.

## 5. 판정

정상 정답지는 #2439의 표 겹침·overflow 수정이 기준 출력과 일치함을 확인하는 유효한
오라클이다. 추가 소스 변경 없이 기존 수정과 회귀 테스트를 유지한다.
