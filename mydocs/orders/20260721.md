## PR #2680 순수 RawSvg 프리페치 경로 보완 준비

- [PR #2680](https://github.com/edwardkim/rhwp/pull/2680)은 [PR #2654](https://github.com/edwardkim/rhwp/pull/2654)의
  조기 재렌더 위에, [PR #2522](https://github.com/edwardkim/rhwp/pull/2522)에서 제안한 순수 `rawSvg` SVG data URL
  프리페치만 이식한다. 내부 raster data URL이 든 SVG는 중복 처리하지 않는다.
- 실제 Studio `PageLayerTree` bbox 계약인 `x/y/width/height`를 고정하는 회귀 테스트를 추가했다. 구형
  `getPageRenderTree`의 `w/h`와 혼동하지 않으며, #2522의 필드명 보정은 필요하지 않다.
- 최신 `devel` rebase 중 [#2635](https://github.com/edwardkim/rhwp/issues/2635)의 URL 미수집 fallback은 유지했다.
  URL을 만들 수 있을 때는 #2680의 실제 프리페치 완료 경로를 사용하고, 만들 수 없을 때만 기존 조기 재렌더로 복구한다.
- `npm test` 466건, production build, 400ms RawSvg first-paint headless E2E를 통과했다. 시각 증적과 상세 판단은
  [PR #2680 검토 기록](../pr/archives/pr_2680_review.md)에 보존한다.
- 최신 PR head의 CI, CodeQL, Render Diff 성공을 확인한 뒤 merge한다. merge 후 [PR #2522](https://github.com/edwardkim/rhwp/pull/2522)는
  대체 PR 안내 코멘트와 함께 close한다.
